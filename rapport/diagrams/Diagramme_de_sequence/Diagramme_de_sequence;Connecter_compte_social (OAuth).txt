@startuml agent-market-sequence-oauth-account-social
!theme plain
title Séquence — Connexion d’un compte social (OAuth)

actor Utilisateur
participant "Next.js" as Web
participant "API Fastify" as API
participant "Fournisseur OAuth\n(Meta, X, TikTok, LinkedIn…)" as OAuth
database "MongoDB" as DB
participant "Redis \n Cache temporaire" as Cache
participant "Celery \n Service de traitement asynchrone" as Worker

== Démarrage de l’authentification OAuth ==

Utilisateur -> Web : Choisir un réseau social à connecter
Web -> API : Demande d’authentification OAuth

API -> API : Générer URL d'autorisation OAuth
API -> Cache : Sauvegarder l’état de session\n(userId, workspaceId, retour) (TTL 10 min)
Cache --> API : OK

API --> Web : URL d'autorisation + state
Web -> OAuth : Redirection vers le fournisseur

Utilisateur -> OAuth : Authentification et consentement
OAuth -> API : Redirection callback (code + state)

== Traitement du callback ==

API -> Cache : Récupérer et supprimer l'état (state)
API -> OAuth : Échanger le code contre des tokens
OAuth --> API : Tokens + informations du compte

alt Compte avec sélection d’entité (Page / compte professionnel)

  API -> Cache : Stocker temporairement le contexte parent
  API --> Web : Redirection vers sélection des entités

  Utilisateur -> Web : Sélectionner une entité (page / compte)
  Web -> API : Demande des entités disponibles

  API -> OAuth : Récupérer les entités liées
  OAuth --> API : Liste des entités
  API --> Web : Liste des pages / comptes

  Utilisateur -> Web : Valider le choix
  Web -> API : Association du compte sélectionné

  API -> DB : Enregistrer le compte social connecté

else Connexion directe (Twitter, TikTok, LinkedIn, Instagram login)

  API -> DB : Enregistrer le compte social connecté

end

== Finalisation ==

API -> API : Générer événement "compte connecté"
API -> Cache : Publier notification système

API --> Web : Redirection vers page des comptes connectés

== Synchronisation (asynchrone) ==

opt Import initial des données (posts, métriques, insights)

  Worker -> API : Déclenchement tâche d'import
  API -> Worker : Lancer import du compte connecté

  Worker -> OAuth : Récupérer posts et statistiques
  OAuth --> Worker : Données sociales

  Worker -> API : Envoyer données importées
  API -> DB : Stocker les données analytiques

end
