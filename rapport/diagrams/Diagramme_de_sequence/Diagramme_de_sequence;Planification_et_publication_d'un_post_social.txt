@startuml agent-market-sequence-publish-post
!theme plain
title Séquence — Planification et publication d’un post social

actor Utilisateur
participant "Next.js" as Web
participant "API Fastify" as API
database "Base de données" as DB
participant "Redis\nFile de traitement" as Queue
participant "Celery Worker\nService de publication asynchrone" as Worker
participant "Connecteurs sociaux\n(X, Meta, TikTok…)" as Connector
participant "SocketCluster\nService temps réel" as Realtime

== Création et planification du post ==

Utilisateur -> Web : Créer un post avec date de publication
Web -> API : Enregistrer ou planifier le post

API -> DB : Créer / mettre à jour le post
DB --> API : Post enregistré

alt Post planifié
  API -> Queue : Enregistrer une tâche de publication différée
  Queue --> Worker : Déclenchement à l’échéance
end

API --> Web : Confirmation de création
Web --> Utilisateur : Post enregistré

== Publication du post ==

note over Worker
Le service de publication traite les posts
dont la date de publication est atteinte.
end note

Worker -> API : Récupérer les posts prêts à être publiés
API -> DB : Charger post + comptes connectés + médias
DB --> API : Données complètes
API --> Worker : Données de publication

loop Pour chaque compte social cible
  Worker -> Connector : Publier le post
  Connector -> Connector : Appel API du réseau social
  Connector --> Worker : Résultat (succès ou erreur)

  Worker -> API : Mettre à jour le statut de publication
  API -> DB : Enregistrer le résultat
end

Worker -> API : Mettre à jour le statut global du post
API -> DB : Statut = PUBLIÉ ou ÉCHEC

== Notification en temps réel ==

API -> Realtime : Émettre événement de mise à jour
Realtime --> Web : Notification WebSocket
Web --> Utilisateur : Mise à jour de l’interface

@enduml
